# AxomRank

**Free, bilingual (English and Assamese), source-checked preparation for Assam government exams:** ADRE Grade III and IV, APSC CCE, Assam TET and Assam Police.

▶ **[Open the app](https://axomrank.pages.dev/?utm_source=github&utm_medium=profile)** · works offline · no login needed to start
📰 **[Blog](https://axomrank.github.io/axomrank-blog/)**: exam analysis from real papers

## Learn
| | |
|---|---|
| [AxomRank app](https://github.com/axomrank/axomrank.github.io) | Assam history (93 lessons), Indian polity, Indian history, geography, maths, reasoning |
| [Ahom kings](https://github.com/axomrank/ahom-kings-lessons) | All 41 Ahom reigns, one short lesson each |
| [Assam Through Time](https://github.com/axomrank/assam-history-map) | Year-by-year map of Assam's kingdoms, 350 CE to today |
| [Ahom kingdom](https://github.com/axomrank/ahom-kingdom-history) | The story of the Ahom kingdom, chapter by chapter |

## Open data
| | |
|---|---|
| [PYQ](https://github.com/axomrank/assam-exam-pyq) | 2,398 previous-year questions from 23 Assam exam papers, with answers and topic tags |
