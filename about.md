# About AxomRank

AxomRank is a learning app for Assam's learners and exam aspirants. It offers short, bilingual (English and Assamese) lessons and previous-year question practice for ADRE, Assam TET, APSC CCE and Assam Police. It works offline and can be installed from the browser.

AxomRank is run as a sole proprietorship by **Angsuman Das**.

## How we check facts

- Exam statistics come from the real question booklets. The data and code are open in the [PYQ repository](https://github.com/axomrank/assam-exam-pyq).
- We say which answers come from an official key and which are our own worked solutions.
- History content names its sources. Where sources disagree, we say so instead of picking one silently.
- We do not claim Assamese editorial review that has not happened.

## Corrections

If you find an error, open an issue on the [blog repository](https://github.com/axomrank/axomrank-blog/issues). Include the page, the claim, and a source. We correct the page and note the date of the change.
